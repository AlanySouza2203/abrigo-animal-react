## 📌 Sobre o projeto

O **AdotePet** é uma aplicação web moderna e responsiva desenvolvida com React, Vite e Tailwind CSS, com o objetivo de apresentar animais disponíveis para adoção e aproximá-los de pessoas interessadas em oferecer um lar.

A plataforma busca incentivar a adoção responsável, proporcionando uma interface intuitiva para visualizar os animais, navegar pelas categorias e conhecer melhor o processo de adoção.

O projeto também permite praticar conceitos de desenvolvimento front-end, componentização, organização de código, criação de interfaces responsivas e construção de experiências interativas para o usuário.

## 💻 Como executar o projeto

### Pré-requisitos

- Node.js instalado.
- npm instalado.
- Git instalado para clonar o repositório.

### 1. Clone o repositório

```bash
git clone https://github.com/AlanySouza2203/abrigo-animal-react.git
```

### 2. Entre na pasta do projeto

```bash
cd abrigo-animal-react
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Acesse o endereço local exibido pelo Vite no terminal, geralmente `http://localhost:5173/`.

### 5. Gere a versão de produção

```bash
npm run build
```
